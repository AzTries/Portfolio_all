# Sneha Guchait — Portfolio (React)

A responsive portfolio site built with React + Vite. Features modular components, smooth navigation, and the same elegant design as the original HTML version.

**Live:** https://sneha-azz-portfolio.vercel.app

## Quick Start

```bash
npm install
npm run dev
```

Visit http://localhost:5173

## Build & Deploy

```bash
npm run build
```

Push to GitHub and Vercel auto-redeploys.

## Features

- **Index page** — Sneha Guchait with creative alias: Azz
- **Illustrations** — Links to Canva portfolio
- **Storyboarding & Narrative Design** — Coming soon pages
- **AI Engineering** — Project showcase with all repos and live demos

## Tech Stack

- React 18 (Vite)
- CSS (no frameworks)
- Modular component structure
- Mobile-responsive
